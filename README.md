# Calicut University B.Ed Special Education (HI) Study Portal

ഈ പോർട്ടൽ കാലിക്കറ്റ് സർവ്വകലാശാല B.Ed സ്പെഷ്യൽ എജ്യുക്കേഷൻ (Hearing Impairment) വിദ്യാർത്ഥികൾക്ക് പഠനകാര്യങ്ങൾ എളുപ്പമാക്കാനും പരീക്ഷകൾക്ക് മികച്ച രീതിയിൽ തയ്യാറെടുക്കാനും വേണ്ടി തയ്യാറാക്കിയ ഒരു ഇന്ററാക്ടീവ് സ്റ്റഡി പ്ലാറ്റ്‌ഫോമാണ്.

### പ്രധാന സവിശേഷതകൾ:
- **കോഴ്സ് നോട്ടുകൾ:** പ്രധാന യൂണിറ്റുകളുടെ ലളിതമായ മലയാളത്തിലും ഇംഗ്ലീഷിലുമുള്ള പഠനക്കുറിപ്പുകൾ.
- **പരീക്ഷാ സഹായി:** 5 മാർക്ക്, 10 മാർക്ക് മോഡൽ ഉത്തരങ്ങൾ.
- **പഠന സൗകര്യങ്ങൾ:** പോമോഡോറോ ടൈമർ (Pomodoro Timer), ഫോണ്ട് വലുപ്പം മാറ്റാനുള്ള സൗകര്യം, റീഡിംഗ് മോഡുകൾ.
